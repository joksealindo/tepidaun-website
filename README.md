# Tepidaun Website

Homepage awal Tepidaun menggunakan HTML, CSS, dan JavaScript vanilla.

## Preview lokal
Buka `index.html` di browser atau jalankan server statis dari folder ini.

## Struktur
- `index.html` — struktur homepage
- `styles.css` — gaya responsif desktop dan mobile
- `script.js` — menu mobile dan tahun footer
- `assets/` — logo, hero, gambar empat pilar, dan font Bariol

## Catatan
Ini merupakan implementasi awal untuk ditinjau. Tautan halaman pilar mengarah ke folder yang akan dikembangkan pada tahap berikutnya.

# Assets Tepinatura

Folder ini digunakan untuk menyimpan seluruh aset visual halaman Tepinatura.

## Rencana isi
- `hero/` — gambar hero dan slide carousel
- `products/` — foto produk dan thumbnail
- `icons/` — ikon pendukung bila diperlukan

Gunakan nama file yang konsisten dan huruf kecil. Optimalkan ukuran gambar sebelum diunggah agar halaman tetap ringan.
